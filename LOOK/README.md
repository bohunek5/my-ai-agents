# LOOK

Local dashboard for checking one localhost site in four device frames at once.

```bash
cd /Users/karolbohdanowicz/my-ai-agents/LOOK
npm start
```

Default preview target: `http://localhost:3000`.

Use another target:

```bash
TARGET_URL=http://localhost:5173 PORT=3001 npm start
```

Then open:

```text
http://localhost:3001/?url=http%3A%2F%2Flocalhost%3A3000
```
