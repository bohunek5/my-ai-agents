# NAILBAR

Lokalny frontend projektu NailBar przygotowany na bazie publicznych materiałów z nailbar.com.pl.

## Uruchomienie

```bash
npm run dev
```

Adres lokalny: `http://localhost:3001`

## Zaimplementowane

- lokalna, responsywna wersja strony z prawdziwymi materiałami NailBar,
- live chat działający demonstracyjnie w przeglądarce,
- newsletter zapisujący adres lokalnie,
- kompletna sekcja case studies / metamorfozy: 6 realizacji, filtry, osobne podstrony, proces, harmonogram, efekty docelowe, zalecenia i galerie,
- social wall gotowy do podpięcia pod API,
- przełącznik PL/EN,
- panel dostępności: powiększenie tekstu, kontrast, ograniczenie animacji, wyróżnienie linków,
- wirtualna wycieczka z posiadanych zdjęć,
- zakładka doradcza z formularzem,
- osobna podstrona sklepu ze 100 produktami, cenami i kategoriami,
- oryginalne widoki produktowe Orbitvu 360 dla 52 produktów, zapisane lokalnie jako 2010 klatek,
- działające lokalnie podstrony produktów, wariant +10 ml, koszyk i finalizacja zamówienia.

## Wymaga integracji po uzyskaniu dostępu

- prawdziwa obsługa formularzy i newslettera,
