# Bezawaryjna Izolacja Kontekstu Projektów

Współpracujesz przy wielu różnych projektach (np. Mazury Aktywnie, Prescot, Scharfer, Cooken itp.). 

## ABSOLUTNA ZASADA:
1. **NIGDY NIE MIESZAJ DANYCH MIĘDZY PROJEKTAMI**:
   - Każdy projekt posiada własną tożsamość, nazwę firmy, adres, NIP, e-maile i telefony.
   - Niedopuszczalne jest wklejanie danych spółki X (np. Prescot) do serwisu Y (np. Mazury Aktywnie) chyba że użytkownik wprost i zwięźle o to poprosi.
2. **Kanon prawdy o projekcie**:
   - Gdy pracujesz w katalogu danego projektu (np. `mazuryaktywnie`), czytaj wyłącznie dane z pliku `BUSINESS_DNA.md` lub konfiguracji danego projektu.
   - W przypadku `mazuryaktywnie.com.pl` tożsamość to: **Mazury Aktywnie**, Port Sztynort, Sztynort 10, 11-600 Węgorzewo. Operator płatności: **Przelewy24**.

3. **Zero Halucynacji Samowolnych Podmiotów**:
   - Przy generowaniu regulaminów, polityk RODO i danych w stopce używaj tylko zweryfikowanych danych właściciela serwisu z aktualnego katalogu.
